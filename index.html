📄 Файл тестовых запросов listings.http REST Client VS Code

Готовый listings.http файл с 14 запросами для проверки сервера в VS Code. 

@host = http://localhost:5000

### 1. Список всех объявлений
GET {{host}}/api/listings

### 2. Фильтр по району и цене
GET {{host}}/api/listings?district=Чиланзар&maxPrice=50000

### 3. Сортировка по цене (по убыванию) [Бонус]
GET {{host}}/api/listings?sort=-price

### 4. Счётчик объявлений [Бонус]
GET {{host}}/api/listings/count

### 5. Пагинация (Страница 1, 2 элемента) [Бонус]
GET {{host}}/api/listings?page=1&pageSize=2

### 6. Одно объявление
GET {{host}}/api/listings/1

### 7. Несуществующее — ожидаем 404
GET {{host}}/api/listings/999

### 8. Создать — ожидаем 201 и заголовок Location (с полем address)
POST {{host}}/api/listings
Content-Type: application/json

{
  "title": "3-комн. в Юнусабаде",
  "price": 62000,
  "district": "Юнусабад",
  "rooms": 3,
  "address": "ул. Ахмад Дониш, 24"
}

### 9. Ошибка валидации — ожидаем 400
POST {{host}}/api/listings
Content-Type: application/json

{
  "title": "",
  "price": -5,
  "district": "Чиланзар",
  "rooms": 2,
  "address": ""
}

### 10. Заменить — ожидаем 204
PUT {{host}}/api/listings/1
Content-Type: application/json

{
  "title": "2-комн. рядом с метро (цена снижена)",
  "price": 45000,
  "district": "Чиланзар",
  "rooms": 2,
  "address": "ул. Чиланзарская, 12, кв. 14"
}

### 11. Частичное обновление цены (PATCH) [Бонус]
PATCH {{host}}/api/listings/1/price
Content-Type: application/json

{
  "price": 43000
}

### 12. Удалить — ожидаем 204, повторно — 404
DELETE {{host}}/api/listings/3
